# 경희대학교 휘장

`KHUSeal.png`는 경희대학교가 배포하는 단색 Red 대학 휘장 원본입니다.

- 안내: https://www.khu.ac.kr/kor/user/contents/view.do?menuNo=200029
- 원본: https://www.khu.ac.kr/resources/user/download/University_Seal_02_PNG_2021.zip (`RED-01.png`)

`scripts/build-icons.swift`가 투명 여백을 제외한 원본 비율을 유지하며 macOS 앱 아이콘과 메뉴 막대용 이미지를 생성합니다. 메뉴 막대는 macOS 템플릿 렌더링으로 밝은/어두운 배경에 맞춥니다.

휘장에 대한 권리는 경희대학교에 있습니다. CampusBar는 개인용 비공식 앱입니다.
